# 隐私说明

## 仓库与执行数据

本仓库发布人工编写的配置、空 Memory 模板、完全虚构的通用流程和标准库校验工具。不包含私人模型绑定、凭据、本机私有配置或真实运行记录，也不实现遥测上传。

工作流由 ZCode 宿主解释执行。宿主可能把项目代码、diff、测试信息及用户输入发送给其配置的模型服务。本仓库无法控制服务保留政策、网络传输或宿主权限；使用前应核查宿主和模型服务隐私政策、项目授权与敏感数据处理要求。

## 最小化传递

只传递当前任务必需的代码与脱敏测试摘要。不读取无关文件、不将密钥放入 Prompt、不在公开 Issue 附带原始会话、日志或真实 Memory。环境原因应概括到足以说明证据局限的程度，不披露内部账号与主机细节。

## Memory 与公开发布

discriminator 仅 proposal；主会话展示建议，用户明确确认后才写入。审批不是公开授权，真实 Memory 默认私有，不应加入此仓库。`.gitignore` 是兜底而非保密证明，发布前仍应检查暂存内容和文件来源。

内容校验扫描全部发布文本（含校验器及测试源码），但只识别有限模式，不能保证发现全部秘密或专有信息。安装脚本不执行网络请求、不删除用户文件，只复制白名单；失败时只清理自身临时文件，显式覆盖以安全替换方式处理。更多限制见[架构](architecture.md)、[Memory 政策](memory-policy.md)及[安全政策](../SECURITY.md)。
